# Wydatki

Prosta aplikacja PWA do zapisywania wydatków (PLN/EUR, kategorie, głos, zdjęcie paragonu z OCR, raporty, CSV). Dane tylko lokalnie na telefonie (IndexedDB).

Aplikacja: https://tazo88.github.io/wydatki-app/

W aplikacji: przycisk ❓ „Jak używać”.

Pliki statyczne; workflow `.github/workflows/pages.yml` publikuje je na gałąź `gh-pages`.
